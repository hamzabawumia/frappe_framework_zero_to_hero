# 08. Suggested Beginner Roadmap

## Week 1
- App lifecycle: create, install, migrate, restart
- Push your app to GitHub

## Week 2
- Build one DocType + lifecycle validations
- Add Desk client script and one server script

## Week 3
- Build one Desk page
- Build one portal list/detail flow
- Build one multi-step web form

## Week 4
- Build one script report + one query report
- Apply role permissions and workspace restrictions
- Rehearse Docker deployment notes
